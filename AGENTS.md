# Workspace Instructions

## Commit attribution

Follow the [commit attribution policy](.github/CONTRIBUTING.md) for every new
commit: credit `GetMeElon <dzjchu@gmail.com>`, retain human co-authors, and identify
each participating AI assistant with an `AI-assisted-by:` trailer.

This folder is used for rapid hackathon projects.

- Prefer fast, working end-to-end demos over heavy scaffolding.
- For projects created in this folder, commit and push to the configured GitHub remote after meaningful changes unless the user explicitly asks not to.
- Keep dependency additions explicit and minimal.
